# グラフカードUI刷新計画

最終更新日: 2026-08-14

## 目的

分析・振り返り・実績管理に残る旧グラフカードを、現在のReport Appの情報階層、余白、状態表示、モバイル方針へ統一する。グラフの集計値や切替機能は維持し、グラフを読む前に「何の指標か」「現在値は何か」「比較対象は何か」が分かるカードへ再設計する。

## 共通設計方針

- カード見出しを `kicker / title / description / primary value / controls` の順に統一する。
- 凡例、期間、単位、データ件数をグラフ本体と分離し、補助情報として整理する。
- 強い影、過剰なグラデーション、旧式の枠線を抑え、既存の新UIトークンへ合わせる。
- 空データ、読込中、表示失敗をグラフ枠内の共通状態として扱う。
- モバイルはページ全体の横スクロールを発生させず、操作ボタンと凡例を折り返す。
- Chart.jsのデータ構造、集計ロジック、アクセシブルなラベルは維持する。

## 工程

### 工程0: モバイルヘッダーと条件指定の重なり修正（完了）

- 分析／振り返りレポートの条件指定より、開いたドロワーメニューを前面に表示する。
- 期間指定を含む全条件で390px幅を確認する。
- メニュー開閉、背景タップ、Escape、リンク遷移を維持する。

検証結果: 分析の期間指定／振り返りレポートの路程指定を390px幅で確認。ドロワー`z-index: 280`、ヘッダー`250`、メニュー内座標の最前面要素がドロワー配下であることを確認した。

### 工程1: グラフカード共通基盤と全画面台帳（完了）

- グラフ種別、利用画面、主要値、切替操作、空状態を一覧化する。
- 共通カード、見出し、主値、凡例、グラフフレーム、空状態のクラスを定義する。
- 分析／レポートを基準画面としてPC・モバイルの完成形を固定する。

### 工程2: 「分析する」ページ（完了）

- 月別／路程別推移、ランキング、属性分布、平均金額比較を新カードへ変更する。
- 個人／全体タブ、ランキングモード、平均金額モードの切替を維持する。
- ドーナツカードは主値・目標・達成率の優先順位を整理する。

### 工程3: 「振り返りレポート」ページ

- 属性別分析と平均金額グラフを工程2と同じカード構造へ統一する。
- 印刷・エクスポート時の可読性と、長い期間名・部署名の折返しを確認する。
- 表・ランキング・文章サマリーとグラフの視覚的な優先順位を整理する。

### 工程4: 実績管理・個人実績へ横展開

- 実績管理トップ、過去実績、メンバー詳細／履歴の推移グラフと達成率グラフを統一する。
- AJAX部署切替後のChart破棄・再生成、表示モード切替を維持する。
- 同じ指標のカードは管理者／個人画面で同じ構造を使う。

### 工程5: 残存グラフ監査と統合検証

- 入力画面のミニグラフを含む残存グラフを監査する。
- PC、390px、空データ、長いラベル、WV固有指標、補正実績を横断確認する。
- 対象テスト、全体テスト、Django check、migration、BOM、差分監査を完了する。

## 完了条件

- 分析・振り返りレポートを含む全グラフカードが新UIの共通規則へ揃う。
- モバイルでページ全体の横スクロールやメニュー隠れが発生しない。
- 既存の集計値、グラフ切替、AJAX再描画、エクスポート機能に回帰がない。
- 各工程を独立コミットし、pushは利用者の明示依頼時のみ行う。
