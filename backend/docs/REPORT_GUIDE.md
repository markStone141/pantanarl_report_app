# 報告者向けガイド

## 1. ログイン

1. ログイン画面で `REPORT` を選択
2. パスワードを入力してログイン
3. 報告対象の部署ボタンを押して報告フォームへ移動

## 2. 報告の送信

1. 報告日・責任者を選択
2. メンバー行を入力
3. `送信` を押す

## 3. 同日再送信の挙動（重要）

- 同じ日・同じ部署にすでに報告がある場合、新規で増えずに上書きされます。
- その日の同部署データは最終送信内容が1件として保持されます。

## 4. 修正と削除

- 送信履歴から `編集` で内容を修正できます。
- 誤送信時は `削除` を実行します。

## 5. 注意点

- WV は `CS件数` と `難民件数` を分けて入力します。
- Style 部署は現場入力が不要です。

## 6. 振り返りレポートの期間指定

1. 振り返りレポートを開き、部署を選びます。
2. 集計単位で「期間指定」を選び、開始日と終了日を入力します。
3. 「表示」を押すと、両端の日付を含む期間の実績・補正実績を集計します。月をまたぐ期間も選べます。
4. 「AI用テキスト」「JSON」も、表示中と同じ部署・期間で出力します。

既存の「月」「路程」も引き続き選択できます。開始日・終了日が両方未指定なら直近30日を使い、日付が逆の場合は入れ替えて表示します。
期間指定での目標は、期間内に設定された日次部署目標の合計を使います。
