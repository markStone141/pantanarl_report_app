# 全アプリUI 公開前統合監査

実施日: 2026-08-12

## 対象

- Django 11アプリの全URL、権限分岐、共通NAV、ログイン・ログアウト
- PC／モバイル用CSS、フォーム、AJAX、戻る操作、空・読込・失敗・完了状態
- 工程1〜9で変更したUIと既存の認証・保存・集計処理の回帰

## 結果

- アプリURL 108件を列挙し、名前付きURLの重複がないことを確認した。
- 全394テストが成功し、一般利用者／管理者／staffの権限別導線、認証、保存、削除、検索、AJAX応答の既存契約を維持した。
- Django check、migration差分、BOM、JavaScript構文、Git差分検査が成功した。
- 共通NAVを使う画面は共通モバイルドロワーへ統合済みで、独立アプリは専用ログアウトと権限差を維持している。
- 旧 `talks` 専用ドロワーのCSSとJavaScriptは工程7以降参照されていなかったため削除した。
- CSSの同一宣言は主に汎用レイアウトとアプリ固有ブレークポイントに分散している。カスケード変更を伴う一括統合は行わない。

## 残リスク

- `npm run lint` は依存する `eslint` がローカルに未配置のため起動できない。JavaScriptは全管理対象ファイルを `node --check` で検査済み。
- この工程ではPUSH・デプロイを行わないため、公開環境でのPC／モバイル実画面確認は未実施。
- 実ブラウザ確認では、主要画面のドロワー、長い表・フォーム、AJAX失敗表示、ブラウザバック、ログアウト後の復帰を確認する。

## 公開判断

ローカルの自動テストと静的監査の範囲では、PUSHを止める問題はない。
PUSH・デプロイ後に公開環境のPC／モバイル主要導線を確認し、その成功をもって公開完了とする。
